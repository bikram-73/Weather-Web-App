# Weather Web App 🌦️

A simple weather web application built using HTML, CSS, and JavaScript. The project provides a clean interface for displaying weather information.

## Features

- Clean and user-friendly interface
- Weather information displayed in a card-based layout
- Responsive styling

## Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling
- **JavaScript** — Functionality

## Project Structure

```text
weather/
├── images/
├── index.html
├── style.css
└── README.md
```

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/bikram-73/weather-web-app.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.
